# Portfolio — Ryma DRISS

## Ouvrir le site sur Windows

1. Décompressez **tout** le fichier ZIP (clic droit > Extraire tout).
2. Ouvrez le dossier extrait `Portfolio_Ryma_DRISS_Pret_A_Lancer`.
3. Double-cliquez sur `index.html` pour ouvrir le portfolio dans Chrome ou Edge.
4. Gardez toujours les dossiers `css`, `js` et `documents` à côté de `index.html`.

## Ouvrir dans Visual Studio Code

1. VS Code > Fichier > Ouvrir un dossier > choisissez ce dossier.
2. Ouvrez `index.html` avec l'extension Live Server si vous souhaitez un serveur local.
3. Modifiez le contenu dans `index.html`, le design dans `css/style.css`, et les interactions dans `js/main.js`.

## Publier sur Netlify

Glissez le **dossier extrait** sur https://app.netlify.com/drop . Le fichier `index.html` doit être directement à la racine du dossier déposé.

## Structure

- `index.html` : structure et contenu
- `css/style.css` : couleurs, polices, disposition et animations
- `js/main.js` : menu, filtres, cartes et projets GitHub
- `documents/CV_Ryma_DRISS.pdf` : CV téléchargeable

Les polices Google Fonts et la récupération automatique des dépôts GitHub requièrent une connexion Internet. Le reste du site et ses couleurs fonctionnent en local.
